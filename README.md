# .github

Organization-wide files for [Nephrite](https://getnephrite.dev), a calm, jade-inspired color theme.

- [`profile/README.md`](profile/README.md): the page shown at [github.com/Nephrite-theme](https://github.com/Nephrite-theme).
- [`CONTRIBUTING.md`](CONTRIBUTING.md): how to request, build and submit a port ([español](CONTRIBUTING.es.md)).
- [`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE): issue forms shared by every repository in the organization.

**Español:** archivos de la organización [Nephrite](https://getnephrite.dev/es/). `profile/README.md` es la página que se muestra en [github.com/Nephrite-theme](https://github.com/Nephrite-theme).
